Deploy no Easypanel (Pronto para Nuvem)

Este projeto conta com Dockerfile multi-stage ultra-leve e docker-compose.yml prontos. No Easypanel, basta criar um novo aplicativo, apontar para o seu repositório no GitHub e fazer o deploy em segundos!

Passo 1: Repositório no GitHub

Repositório: https://github.com/GuilhermeAzespo/JobSearch (Branch: main)

Passo 2: No painel do Easypanel

Clique em + New App → App → Selecione Git Repository e insira a URL.

Passo 3: Porta e Armazenamento Persistente

Porta: 3000. Volume (opcional): crie um mount de /app/data para manter seus dados preservados.
